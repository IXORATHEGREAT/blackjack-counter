# BJ ELITE - Blackjack Card Counting Pro

A professional-grade blackjack card counting assistant for mobile use.

## Features
- Hi-Lo card counting with true count calculation
- Full basic strategy engine (6-deck S17)
- EV-based deviation suggestions
- Split hand support with proper bet tracking
- Double down with bet doubling
- Insurance recommendations with EV calculation
- Session persistence (LocalStorage)
- Seed-based session sharing
- Recovery mode betting
